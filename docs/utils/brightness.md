## Carbon Brightness Utility

A reference sheet for the `carbon.brightness` CLI tool.

### increase
Increase brightness by `x` percent.
```sh
carbon.brightness increase 10
```

### decrease
Decrease brightness by `x` percent.
```sh
carbon.brightness decrease 10
```

### set
Set brightness to `x` percent.
```sh
carbon.brightness set 60
```

### get
Get current brightness percentage.
```sh
carbon.brightness get
```

### save
Save current brightness level.
```sh
carbon.brightness save
```

### restore
Restore last saved brightness level.
```sh
carbon.brightness restore
```
