## Carbon Audio Utility

A reference sheet for the `carbon.audio` CLI tool.

### increase
Increase volume by `x` percent.
```sh
carbon.audio increase 10
```

### decrease
Decrease volume by `x` percent.
```sh
carbon.audio decrease 10
```

### set
Set volume to `x` percent.
```sh
carbon.audio set 75
```

### get
Get current volume value (range: `0` to `1`).
```sh
carbon.audio get
```

### toggle-mute
Toggle mute on output.
```sh
carbon.audio toggle-mute
```

### toggle-mic
Toggle mute on input/microphone.
```sh
carbon.audio toggle-mic
```
