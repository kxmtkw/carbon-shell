## Carbon Power Utility

A reference sheet for the `carbon.power` CLI tool.

### lock
Lock the session. Requires `hyprlock`.
```sh
carbon.power lock
```

### shutdown
Power off the system.
```sh
carbon.power shutdown
```

### reboot
Restart the system.
```sh
carbon.power reboot
```

### suspend
Suspend/sleep the system.
```sh
carbon.power suspend
```

### hibernate
Hibernate the system.
```sh
carbon.power hibernate
```

### logout
Log out the current user.
```sh
carbon.power logout
```

### bios
Restart and enter BIOS/UEFI.
```sh
carbon.power bios
```
