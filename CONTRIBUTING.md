
# Contributing to CarbonShell

You can contribute to the shell by:

- Bug Fixing 
- Adding new managers
- Adding more functionality to existing managers
- Making more shell themes
- Adding install scripts for other linux distros

## Code of Conduct

I don't know what to add here. 

- Just write python as I did in the codebase.
	- Camel case for classes etc
	- Decapitalized Camel case for functions/methods etc
	- Snake case for variables

- Working on a manager or adding a new manager should ideally only change that part of the code. Do not have random changes all over the codebase unless small.

- If making install scripts for other distros, make sure to check if they work by reinstalling the shell from scratch.
